PERFORMA & KEMUDAHAN

Mengapa Memilih Custom Alert Ini?

Kompatibel OBS Studio & TikTok Live

Berjalan mulus di Browser Source OBS Studio, Streamlabs Desktop, maupun Tautan Web TikTok Live Studio tanpa kendala format.

Ringan & 60 FPS Tanpa Lag

100% murni HTML dan CSS dengan akselerasi GPU perangkat keras. Tidak menggunakan skrip berat, memastikan FPS game tetap stabil.

Salin & Tempel Instan ke SociaBuzz

Cukup salin kode HTML ke kolom HTML dan kode CSS ke kolom CSS di dashboard SociaBuzz. Alert langsung tayang seketika.

Simulator Interaktif Mandiri

PANDUAN PEMASANGAN

3 Langkah Mudah Pemasangan

Panduan praktis menghubungkan tema custom ke SociaBuzz, OBS Studio, dan TikTok Live Studio.

01
File Kode

Buka File Tema Pilihan

Buka folder tema pilihan Anda, lalu buka file sociabuzz-html.html dan sociabuzz-css.css menggunakan aplikasi teks editor atau browser.

› Salin seluruh isi kode HTML
› Salin seluruh isi kode CSS
02
SociaBuzz

Tempel ke Dashboard SociaBuzz

Login ke SociaBuzz, buka menu Kustomisasi Overlay Alert, lalu tempelkan masing-masing kode ke kolom yang bersesuaian.

› Kolom HTML Custom: tempel kode HTML
› Kolom CSS Custom: tempel kode CSS
03
OBS TikTok Live

Hubungkan ke Software Streaming

Ambil URL Overlay Alert dari SociaBuzz, lalu masukkan ke software siaran Anda dengan resolusi Width: 650 dan Height: 220.

› OBS Studio: Tambah Sumber → Browser Source
› TikTok Live Studio: Tambah Sumber → Tautan / Web URL
